Factory Management

Manage Germany's industrial facilities. Each factory costs $200 per cycle. Exclusive contracts cost $1,000 per cycle.

✠ Germany Manpower & Exclusive Workers Configuration
Total soldiers Germany has available to assign to factories. This is the hard cap — items in production lock this MP until finished.
Each country can hire exclusive workers at $25/worker/turn. They only serve that country's exclusive factories and cannot be used by others. A country can reduce or remove their exclusivity at any time.
⏱ Advance Turn
Clicking this reduces the remaining turns on every active production process across all factories. Each process counts down by 1. When a process hits 0, it is marked ready. This also calculates the total turn cost charge.

Active Orders

Each order is a package from a country. Confirm each item as it is produced. When all items in a package are confirmed, you can send the package and it moves to the archive.

Create New Production Order

Select the requesting country, assign a factory (or queue position), then build the item list. Germany provides manpower, fuel, and factories — the country sends raw resources.
